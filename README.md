# SDLC

Language-agnostic, evidence-backed SDLC guidance for people and AI agents.

This repository is the canonical, reviewable version of the guidance. The original GitHub Gist remains available as a snapshot.

## Onboarding order

1. [SDLC.md](SDLC.md) — principles, specifications, workflows, quality, and completion.
2. [HARNESS.md](HARNESS.md) — harness engineering, repository legibility, feedback loops, isolation, and Symphony.
3. [LINEAR.md](LINEAR.md) — issues, milestones, ownership, status, and progress.
4. [AGENT-SKILLS.md](AGENT-SKILLS.md) — research, skills, distribution, versioning, and trust.
5. [MISE.md](MISE.md) — tools, runtimes, environments, tasks, and output handling.
6. [ASPIRE.md](ASPIRE.md) — optional orchestration, testing, previews, deployment, and observability.
7. [OLLAMA.md](OLLAMA.md) — local model serving and agent-runtime validation.
8. [TESTING.md](TESTING.md) — specifications, FIRST tests, UI evidence, and validation.
9. [SECURITY.md](SECURITY.md) — trust boundaries, secret protection, and security checks.
