# Source catalog / Catálogo de fuentes

This repository keeps maintained guidance and source links. It does not distribute copied third-party pages. Copies can include personal names, profile links, client references, or attribution that must not be removed while redistributing the work.

Este repositorio conserva guías mantenidas y enlaces a fuentes. No distribuye copias de páginas de terceros. Las copias pueden incluir nombres personales, enlaces a perfiles, referencias a clientes o atribución que no debe eliminarse al redistribuir la obra.

The former source snapshots were removed as part of the owner-authorized privacy cleanup. No new human review or external-source refresh is claimed. Live sources remain authoritative and untrusted.

Las capturas anteriores se eliminaron como parte de la limpieza de privacidad autorizada. No se declara una nueva revisión humana ni una actualización de fuentes externas. Las fuentes activas siguen siendo autoritativas y no confiables.

## Future evidence / Evidencia futura

Use links to official software documentation, standards, or research records. Do not copy personal profiles or store personal names, contact data, client records, or client brands. Keep software brands, but remove personal identifiers from source locators as well.

Use enlaces a documentación oficial de software, estándares o registros de investigación. No copie perfiles personales ni almacene nombres personales, datos de contacto, registros de clientes ni marcas de clientes. Conserve las marcas de software, pero elimine también los identificadores personales de las ubicaciones de fuentes.

The existing snapshot metadata, body-hash, prompt-injection and human-review checks still apply if a future approved change adds a snapshot. Do not fabricate an attestation or strip required attribution to satisfy a scan. Prefer a source link when redistribution conflicts with privacy or licensing.

Los controles existentes de metadatos, hash del cuerpo, inyección de prompts y revisión humana siguen siendo obligatorios si un cambio aprobado añade una captura. No invente una confirmación ni elimine atribución obligatoria para pasar un análisis. Prefiera un enlace cuando la redistribución entre en conflicto con la privacidad o la licencia.
