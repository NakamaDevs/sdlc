## Seleccionar un rol

El investigador lee y entrega fuentes, incertidumbre y opciones. El implementador realiza un cambio limitado con pruebas.
El probador cuestiona escenarios y entrega evidencia reproducible. El revisor examina cambios finales de forma independiente.
El coordinador reserva responsables, ordena dependencias, integra resultados y verifica el estado de entrega.

Estas son instrucciones portátiles, no configuración nativa del entorno.
Use el esquema instalado de Codex o Claude para configurar roles y permisos. Pruebe descubrimiento antes de conceder escritura.
Use sesiones en serie si no hay delegación. Un alias de modelo o rol Markdown no impone permisos.
