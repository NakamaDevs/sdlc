# Team onboarding

## Shared exercise

Describe a synthetic appointment request from screen to API and storage. Identify the owner of the conflict rule.
Create the system map, then one repository page. Ask a fresh reader to locate and run a focused local check.
Record gaps before assigning implementation. Never treat a written scenario as a passed executable test.

## Role exercise

PM defines acceptance. QA selects failure and boundary cases. Frontend maps visual states to the contract.
Backend proves data invariants and provider behavior. DevOps proves startup, recovery, and two-instance isolation.
Design checks the complete state catalogue. Research records sources, uncertainty, and a bounded recommendation.
Each role produces a handoff another person can verify without the original conversation.

## Complete loop

Specify one small change. Test it with synthetic mocks, validate the provider, then run the real local journey.
Review the final diff and evidence. Prepare rollback and release approval separately from local validation.
A newcomer or fresh agent must recover revisions, result, remaining risk, and next action from the task record.
