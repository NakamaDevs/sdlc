Keep process documentation in this root. Do not add process files to application repositories.

Propose a minimal pilot with acceptance evidence, owned files, isolated state, selected skills, and rollback.

Implementation requires agreed scope and distinct worktrees or file ownership. Preserve concurrent changes.

Return a short result, evidence links, missing decisions, and next action.
Do not configure external accounts, change network policy, deploy, or publish context under this discovery prompt.
