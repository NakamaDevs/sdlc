- Exact validation commands and expected results:
- Time or cost budget, retry limit, stop conditions:
- Return format: result, artifacts, limitations, next action:

## Select one role

Researcher reads and returns sources, uncertainty, and options. Implementer owns a bounded tested change.
Tester challenges acceptance scenarios and returns reproducible evidence. Reviewer examines the final diff independently.
Coordinator reserves ownership, sequences dependencies, integrates results, and verifies the reported delivery state.

These are portable role instructions, not native runtime configuration.
Use the installed Codex or Claude schema to configure roles and tool limits. Test discovery before granting writes.
Use sequential sessions when delegation is unavailable. Never assume a model alias or Markdown role enforces permissions.
