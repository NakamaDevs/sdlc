# Root agent map

Read policies/team.md for accepted team decisions and adapters/README.md for selected capabilities.
Read README.md and docs/system.md before discovery. Read agents/brief.md before delegation or implementation.
Read runtime/README.md before starting resources, tests with data, migrations, seeds, or cleanup.

Keep private analysis and team process in this root. Child repositories retain their instructions and release controls.
Read the target child's nearest instructions before editing it. Pass this root guide explicitly when starting an agent there.
A repository entry permits discovery only. Confirm the task's allowed actions and target account before external writes.
Keep secrets in approved local configuration. Use synthetic fixtures for exercises.

For each task, verify owner, issue, checkout, branch, source revision, allowed files, environment, and acceptance evidence.
Work in a dedicated task worktree. Preserve other agents' changes. Serialize overlapping file ownership.
Use a failing behavior test for code changes, then implement and run the relevant checks.
Record exact commands, exit results, source revisions, artifacts, and unverified behavior.
Stop at missing access, unclear business decisions, conflicting ownership, or the task's approval boundary.

Use reviewed skills selected for the task. Record source revision, license, scope, and update owner in skills.lock.json.
No skills are installed by this template. Do not execute downloaded installers before reviewing them.
Use docs/work/ for plans, evidence, and resumable handoffs. A fresh session verifies the handoff against actual state.
