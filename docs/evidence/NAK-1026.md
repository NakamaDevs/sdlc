## Delivered scope

Seven new English/Spanish guides connect adoption, role-based courses, agent briefs,
workspaces, composable policy, local tools, and remote access. Existing guides link
to them. Both local reading editions include the new guides; publication is deferred.

The Python generator creates a separate root with policy and adapter folders,
repository inventory, onboarding templates, portable agent prompts, and local tools.
Child repositories remain separate. The local runner records bounded output,
exit state, timeout and cancellation. A static report escapes task output.
Optional Playwright capture records a local page, console events, screenshot and video.
HTTP requests are restricted to the selected literal-loopback origin; WebSockets
and service workers are blocked. This is not an OS network sandbox.

## Review and limitations

Self-review checked root/child boundaries, destination preservation, path traversal,
symlinks, process ownership, cancellation, report escaping, browser origin limits,
translation parity, and the difference between mock, integration and deployment evidence.
No independent review is claimed. The pull request remains a draft for the gate below.

The application-specific AppHost, native agent configurations, telemetry collector,
full interaction recorder and live diagnostics UI are adapter work. The starter does
not claim to implement them. Python is the new reference layer; the existing reader
and validators remain Elixir. No machine, VPN, cloud, tracker connection or production
service was configured. Linux and Windows execution are unverified. Process cleanup
currently targets POSIX. No public Gist was updated.

## Existing gate requiring a person

Eighteen archived reference snapshots have review dates older than 30 days.
`en/UPDATE.md` requires human review before recording a new date with
`mise run review:snapshots -- YYYY-MM-DD --confirm-human-review`.
The content scanner and snapshot body hashes are separate from that human attestation.
No review date, snapshot body, or gate was changed to remove this requirement.

Complete the human review, record its date through the existing task, and rerun
`mise run verify` before marking the draft ready. A scoped exception requires the
repository owner's explicit decision and must record the skipped gate accurately.

## Reproduce

```sh
python3 -m unittest discover -s tests -v
mise run verify
```

For the optional browser test, use an isolated environment with the reviewed
Playwright version and matching Chromium, then run:

```sh
SDLC_BROWSER_TEST=1 python -m unittest discover -s tests -p test_browser_capture.py -v
```

The browser test creates and stops its own loopback fixture server. It uses no
application credentials. Revert the implementation commits to remove the starter;
retain the dependency security fix unless a regression requires a different patch.
