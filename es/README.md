# SDLC

Este repositorio ofrece guías del SDLC con evidencia para personas y agentes de IA.

Este repositorio es la guía canónica y revisable. Los Gists públicos son ediciones generadas para lectura.

## Índice de guías

1. [SDLC.md](SDLC.md) — principios, especificaciones, workflows, calidad y finalización.
2. [HARNESS.md](HARNESS.md) — ingeniería del harness, legibilidad del repositorio, ciclos de respuesta, aislamiento y Symphony.
3. [ADOPTION.md](ADOPTION.md) — recepción, estructura del repositorio, plantillas, secuencia de adopción y ritmo de trabajo.
4. [HUMAN.md](HUMAN.md) — recepción con personas en el ciclo, dirección, integración con el editor y protección de la atención.
5. [JOY.md](JOY.md) — trabajo significativo, autonomía, aprendizaje, concentración y alegría del equipo.
6. [BURNOUT.md](BURNOUT.md) — riesgos de burnout, límites de carga de trabajo, recuperación y escalamiento.
7. [STRUCTURE.md](STRUCTURE.md) — monorepos, varios repositorios, submódulos, repositorios meta y automatización del editor.
8. [LINEAR.md](LINEAR.md) — issues, hitos, propiedad, estado y avance.
9. [BRANCHES.md](BRANCHES.md) — nombres estándar, identificadores de issue, propiedad y stacks.
10. [COMMITS.md](COMMITS.md) — commits semánticos y atómicos, autoría, evidencia y revisión.
11. [AGENT-SKILLS.md](AGENT-SKILLS.md) — investigación, skills, distribución, versionado y confianza.
12. [MISE.md](MISE.md) — herramientas, runtimes, entornos, tareas y manejo de salida.
13. [HERDR.md](HERDR.md) — espacios de trabajo persistentes local-first y remote-first.
14. [ASPIRE.md](ASPIRE.md) — orquestación opcional, testing, vistas previas, deploy y observabilidad.
15. [OLLAMA.md](OLLAMA.md) — servicio local de modelos y validación del runtime de agentes.
16. [TESTING.md](TESTING.md) — especificaciones, tests FIRST, evidencia de UI y validación.
17. [SECURITY.md](SECURITY.md) — límites de confianza, protección de secretos y comprobaciones de seguridad.
18. [OWASP.md](OWASP.md) — estándares de OWASP, secretos, almacenamiento, atestación y seguridad antes del lanzamiento.
19. [MCP.md](MCP.md) — transportes de MCP, Code Mode, operación sin estado, autenticación, autorización y aprobaciones.
20. [AI-MLOPS.md](AI-MLOPS.md) — Mojo, MAX, servicio de modelos, evaluación, benchmarks y operaciones de IA.
21. [RUNNERS.md](RUNNERS.md) — runners de GitHub y GitLab alojados o autoalojados, aislamiento y Dagger.
22. [INFERENCE.md](INFERENCE.md) — inferencia local, Apple Silicon, DGX Spark y validación del servicio de modelos.
23. [COMMUNICATION.md](COMMUNICATION.md) — comunicación entre personas y agentes, destilación, verificación y divulgación.
24. [NOTES.md](NOTES.md) — registro local-first, transcripción, notas, consentimiento y comportamiento multiplataforma.
25. [INTEGRATION.md](INTEGRATION.md) — HTTP, SSE, WebSockets, webhooks, orden y recuperación.
26. [CLAUDE.md](CLAUDE.md) — recepción y guía operativa de SDLC específica para Claude.
27. [CODEX.md](CODEX.md) — recepción y guía operativa de SDLC específica para Codex.
28. [CODE-REVIEW.md](CODE-REVIEW.md) — precisión, hallazgos, evidencia, estados y resolución de threads.
29. [HOOKS.md](HOOKS.md) — Git hooks, prek, prevención de filtraciones, smoke tests y comprobaciones locales rápidas.
30. [DAGGER.md](DAGGER.md) — pipelines portables de build, test, caché y entrega.
31. [GITHUB.md](GITHUB.md) — arquitectura CI, rulesets, revisiones de equipos, bypass y runners.
32. [MARKDOWN.md](MARKDOWN.md) — instantáneas de fuentes, conversión local y fuentes no disponibles.
33. [WEB-CAPTURE.md](WEB-CAPTURE.md) — extracción, páginas renderizadas, imágenes y comparación.
34. [UPDATE.md](UPDATE.md) — revisión de documentos, evidencia de comandos y registros de actualización.
